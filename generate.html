A thin wrapper around BWIPP. Pick a symbology, type the data, and pass any BWIPP option as raw JSON — same option names as the BWIPP wiki (e.g. parsefnc, eclevel, version). Use ^FNC1/^FNC2/^FNC3/^FNC4 in the text with "parsefnc": true to embed function characters.
